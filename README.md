# Detecting AI-Generated Wikipedia Articles

A research pipeline for detecting AI-generated text in Wikipedia articles using multiple classification approaches — from classical ML baselines to fine-tuned transformers and large language model zero-shot evaluation.

---

## Overview

This repository contains the full experimental code for a binary classification task:  
**Human-written (0) vs. AI-generated (1)** Wikipedia articles.

Four classifiers are evaluated using **5-fold stratified cross-validation**, with metrics reported as mean ± std across folds:

| Classifier | Features | Model |
|---|---|---|
| LIWC | Psycholinguistic features | Random Forest + SHAP |
| TF-IDF | Bag-of-words n-grams | LinearSVC |
| USE | Universal Sentence Encoder embeddings | Random Forest |
| DistilBERT | CLS-token embeddings | Random Forest |

Additionally, **DistilBERT is fine-tuned end-to-end** for classification, and **Qwen2.5-7B-Instruct** is evaluated zero-shot.

## Scripts

### `article_category_analysis.py`
Analyses which Wikipedia content categories are most associated with AI-flagged articles.  
- Filters AI-flagged rows, explodes pipe-separated categories, and ranks by frequency.  
- Excludes Wikipedia maintenance/metadata categories.  
- Outputs `category_ai_analysis.csv` and `category_ai_analysis_content_only.csv`.

```bash
python article_category_analysis.py
```

---

### `evaluate_llm_model.py`
Combined evaluation pipeline for all four classifiers.  
Toggle each classifier via boolean flags at the top of `main()`:

```python
RUN_LIWC  = True
RUN_TFIDF = True
RUN_USE   = True
RUN_BERT  = True
RUN_SHAP  = True   # SHAP explanations for the LIWC model
```

**Dataset paths** (edit as needed):
```python
text_dataset_path = "dataset_balanced.csv"
liwc_dataset_path = "LIWC-22 Results - dataset_balanced - LIWC Analysis.csv"
```

> **LIWC requirement:** The LIWC classifier requires a LIWC feature CSV generated by the **[LIWC-22](https://www.liwc.app/)** tool (commercial software). To produce the input file, open `dataset_balanced.csv` in LIWC-22, run an analysis on the `content` column, and export the results. The expected output filename is `LIWC-22 Results - dataset_balanced - LIWC Analysis.csv`. Without this file the LIWC classifier is automatically skipped.

```bash
python evaluate_llm_model.py
```

Outputs: `combined_evaluation_results.csv`, SHAP plots in `shap_results_liwc/`.

> **Note:** The USE classifier requires TensorFlow and `tensorflow-hub`.  
> Install with: `pip install tensorflow tensorflow-hub`

---

### `finetune_distillbert.py`
Fine-tunes `distilbert-base-uncased` with a classification head using 5-fold stratified CV.  
Saves each fold's model to `finetuned_distilbert_stratified/fold_N/`.

Key hyperparameters (edit at the top of the file):
```python
MAX_LENGTH    = 512
BATCH_SIZE    = 16
EPOCHS        = 3
LEARNING_RATE = 2e-5
N_SPLITS      = 5
DATASET_PATH  = "dataset_clean.csv"
```

```bash
python finetune_distillbert.py
```

Outputs: fold checkpoints, `finetuned_distilbert_stratified/cv_results.csv`, and a `.log` file.

---

### `qwen_detect.py`
Zero-shot 5-fold CV evaluation using **Qwen2.5-7B-Instruct**.  
The model is not trained — it classifies each test-set article via a carefully crafted system prompt based on Wikipedia's [WP:AISIGNS](https://en.wikipedia.org/wiki/Wikipedia:AI_cleanup) guidelines.

```bash
python qwen_detect.py \
  --csv dataset_balanced.csv \
  --model_path ~/models/Qwen2.5-7B-Instruct \
  --output qwen_kfold_results.csv
```

Arguments:

| Argument | Default | Description |
|---|---|---|
| `--csv` | *(required)* | Path to the dataset CSV |
| `--model_path` | `Qwen/Qwen2.5-7B-Instruct` | Local path or HuggingFace model ID |
| `--text_col` | `content` | Column containing article text |
| `--label_col` | `is_ai_flagged` | Binary label column |
| `--id_col` | `article_id` | Article ID column |
| `--n_folds` | `5` | Number of CV folds |
| `--output` | `qwen_kfold_results.csv` | Output predictions CSV |
| `--log_dir` | `logs` | Directory for logs and fold checkpoints |
| `--seed` | `42` | Random seed |

Outputs: per-fold checkpoint CSVs, full predictions CSV, summary CSV, and a timestamped log file.

## Dataset

The dataset (`dataset_balanced.csv`) is a balanced collection of Wikipedia articles labelled as human-written or AI-generated.

Expected columns:

| Column | Description |
|---|---|
| `article_id` | Unique article identifier |
| `title` | Wikipedia article title |
| `content` | Full article text |
| `categories` | Pipe-separated Wikipedia categories |
| `word_count` | Article word count |
| `is_ai_flagged` | Label: `1` = AI-generated, `0` = human-written |

> The dataset is not included in this repository due to its size.  
> Please contact the authors or refer to the paper for access instructions.

---

## Hardware Notes

- **LIWC / TF-IDF**: CPU only, fast.
- **USE**: Runs on CPU (TensorFlow GPU support for Blackwell/sm_120 is not yet available; the script forces CPU automatically).
- **DistilBERT / BERT embedding extraction**: GPU recommended (`cuda` or `mps`).
- **Fine-tuning DistilBERT**: GPU strongly recommended.
- **Qwen2.5-7B-Instruct**: Requires a GPU with ≥ 16 GB VRAM (bfloat16, `device_map="auto"`).

## Metrics

All classifiers report:

- **Accuracy** — overall correct predictions
- **F1 Score** — binary F1 (positive class = AI-generated)
- **FPR** — false positive rate (human articles incorrectly flagged as AI)

FPR is highlighted because falsely accusing a human editor of using AI is the costlier error in the Wikipedia context.
